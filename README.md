# Exea Labs Bay Area Workshop

Multi-page workshop site built with Vite, Three.js, GSAP, and Lenis.

## Local development

```bash
npm ci
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Pushes to `master` automatically build and deploy the site to GitHub Pages. The deployment workflow uses the Pages-provided base path so assets and internal links work both on a project site and with a custom domain.
